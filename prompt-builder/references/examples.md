# 변환 예시 (거친 요청 → 다듬은 프롬프트)

이 스킬이 실제로 어떻게 요청을 바꾸는지 보여 주는 예시 모음. 세 경로 각각 하나씩.

---

## 예시 1 — 텍스트 작업 (경로 A)

**사용자의 거친 요청**
> 이 계약서 좀 봐줘

**되물을 것 (핵심 1~2개)**
- 무엇을 확인하고 싶은가? (전체 요약 vs 특정 조건)

**다듬은 프롬프트**
```text
[목표] 이 계약에서 중도 해지 시 비용과 절차만 확인한다.
[자료] 아래 발췌문만 근거로 사용한다.
[출력] 조건 / 비용 / 기한 / 근거 문구를 표로 정리한다.
[불확실성] 자료에 없는 내용은 추정하지 말고 '확인 불가'로 표시한다.
```
> 검수 주의: 금액·기한은 원본과 대조하세요.

---

## 예시 2 — 이미지 분석 (경로 B)

**사용자의 거친 요청**
> 이 영수증 정리해줘

**다듬은 프롬프트**
```text
이 이미지에서 거래일시, 상호, 공급가액, 세액, 합계만 추출해 표로 정리해 줘.
각 값 옆에 이미지에서 읽은 원문을 함께 적어 줘.
글자가 불명확하면 추측하지 말고 '판독 어려움'이라고 표시해 줘.
```
> 검수 주의: 한글 상호·금액은 원본과 대조 필수. 작은 글자는 그 부분만 잘라 확대해 다시 넣으세요.

---

## 예시 3 — 이미지 생성 (경로 C)

**사용자의 거친 요청**
> 발표 표지 하나 만들어줘

**먼저 알릴 것**
- Claude는 이미지를 생성하지 못함 → GPT Image·DALL·E 등 생성 모델에 아래 프롬프트를 넣으세요.

**다듬은 프롬프트**
```text
용도: 16:9 세미나 발표 표지
주제: 효과적인 AI 활용 원칙
구도: 중앙에 작은 토큰 블록들이 큰 작업 창 안에 들어가는 모습,
      제목 넣을 왼쪽 위 여백 확보
스타일: 단순한 교육용 인포그래픽, 남색·청록색, 높은 대비
제외: 글자, 로고, 워터마크, 복잡한 배경
```
> 검수 주의: 낮은 품질로 여러 장 → 방향 선택 → 고품질. 제목 글자는 파워포인트에서 직접 넣으세요.
